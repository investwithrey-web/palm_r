# Palm Resort

A professional, fully responsive website for Palm Resort located near Garh Ganga, UP. Built with React and Vite.

## Features
- Modern UI with green and gold styling
- Fully mobile-responsive layout
- Integrated WhatsApp booking and Google Forms enquiry
- Interactive photo gallery with masonry grid and lightbox

## Scripts
- `npm run dev` to start local development server
- `npm run build` to build for production
